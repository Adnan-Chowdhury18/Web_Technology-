# Future Upgrade Ideas

1. Real-time chat between buyer and seller (e.g. via WebSockets or polling)
2. Email notifications for new inquiries, favorites reaching a milestone, or admin actions
3. Map-based area picker with pin-drop location selection instead of a fixed area list
4. Tiered admin roles (super-admin vs. moderator) with different permission levels
5. Rating/review system for sellers after a completed transaction
6. Saved search alerts ("notify me when a new Calculus textbook is listed")
7. Image optimization/thumbnail generation on upload for faster page loads
8. Pagination and bulk actions in the admin panel for large datasets
9. Two-factor authentication for admin accounts
10. Mobile app (or installable PWA) version of ClassSwap
11. Verified student badge (e.g. via university email domain verification)
12. Analytics dashboard for admins (most viewed categories, busiest areas, etc.)
